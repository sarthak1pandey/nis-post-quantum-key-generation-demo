📚 Key Concepts

ECDHE
Elliptic Curve Diffie-Hellman Ephemeral — classical key exchange with forward secrecy.
ML-KEM (Kyber)
Module Lattice KEM — NIST PQC standard, secure against quantum computers.
Hybrid Mode
Combines classical + PQC. Secure if either component is secure.
HKDF
HMAC-based KDF (RFC 5869) — derives strong keys from shared secrets.
HNDL
Harvest Now Decrypt Later — nation-state attack archiving data for quantum decryption.
Forward Secrecy
Ephemeral keys ensure past sessions stay secure even if long-term key is leaked.
IND-CCA
Indistinguishability under Chosen-Ciphertext Attack — strongest KEM security notion.
